# PowerbankRental

Laravel MVC-приложение для аренды портативных зарядных устройств на территории института.

## Возможности

- регистрация и авторизация через Laravel session auth;
- роли `user` и `admin`;
- просмотр станций, слотов и доступных повербанков;
- оформление аренды с проверкой единственной активной аренды;
- возврат повербанка в свободный слот;
- демо-оплата без реального банка;
- привязка карт без хранения полного номера;
- история аренд, платежи, уведомления и обращения;
- админ-панель для пользователей, станций, слотов, повербанков, тарифов, аренд, возвратов, обращений, отчётов и журнала действий.

## Локальный запуск

```bash
composer install
npm install
npm run build
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Для локальной разработки можно использовать SQLite, изменив `.env`. Реальные SSH/MySQL пароли нельзя сохранять в репозитории.

Начальный администратор после сидов:

- `admin@example.com`
- `password`

Пароль администратора нужно сменить после развёртывания.
