# Powerbank Rental

Дипломный проект: информационная система для учёта и выдачи пауэрбанков в учебном заведении. Приложение покрывает полный жизненный цикл оборудования — от регистрации и хранения до заявки, выдачи, возврата, обслуживания и отчётности.

## Возможности

- регистрация и авторизация пользователей;
- каталог оборудования и оформление заявок на выдачу;
- отдельные кабинеты пользователя, сотрудника и администратора;
- согласование, выдача, возврат и отклонение заявок;
- управление оборудованием, категориями и местами хранения;
- обращения о неисправностях и контроль их статусов;
- уведомления, отчёты и журнал действий;
- разграничение доступа по ролям и серверная валидация данных.

## Стек

- PHP 8.3, Laravel 13;
- Blade, JavaScript и Tailwind CSS 4;
- MySQL в production, SQLite для тестов;
- Vite;
- PHPUnit;
- Nginx и PHP-FPM.

## Локальный запуск

Понадобятся PHP 8.3+, Composer и Node.js.

```bash
git clone https://github.com/ADIPISKAR/Diplom.git
cd Diplom
composer run setup
npm install
php artisan serve
```

Чтобы наполнить базу демонстрационными данными, сначала задайте собственные пароли в локальном `.env`:

```dotenv
ADMIN_SEED_PASSWORD=
EMPLOYEE_SEED_PASSWORD=
```

Затем выполните:

```bash
php artisan db:seed
```

Файл `.env` исключён из Git. Репозиторий содержит только безопасный шаблон `.env.example` без рабочих паролей и ключей.

## Проверка

```bash
composer test
npm run build
```

## Основные каталоги

- `app/Http/Controllers` — пользовательские, административные и служебные сценарии;
- `app/Models` — доменные модели;
- `database/migrations` — схема базы данных;
- `database/seeders` — демонстрационные данные;
- `resources/views` — интерфейс на Blade;
- `routes/web.php` — маршруты и ролевые зоны;
- `tests` — автоматические тесты;
- `deploy` — пример production-конфигурации.

## Безопасность

Секреты читаются только из переменных окружения. Создание начальных административных учётных записей требует явно заданных паролей и завершается ошибкой, если они отсутствуют. Перед публикацией текущие файлы и история Git были проверены на ключи, токены, приватные ключи и случайно добавленные `.env`-файлы.
