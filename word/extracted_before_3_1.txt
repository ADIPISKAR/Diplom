Аннотация
Выпускная квалификационная работа посвящена проектированию и разработке веб-приложения для аренды портативных зарядных устройств в учебном заведении. Разрабатываемая система предназначена для упрощения процесса получения пауэрбанка, контроля текущей аренды и возврата устройства через станцию выдачи.
В ходе анализа предметной области были определены основные функциональные требования к веб-приложению, изучены особенности организации сервиса аренды пауэрбанков и выполнен сравнительный анализ существующих решений. На основании полученных данных был обоснован выбор средств разработки, необходимых для создания пользовательской части, административного раздела и базы данных.
В результате проделанной работы было создано веб-приложение, которое позволяет пользователям регистрироваться в системе, просматривать доступные станции, оформлять аренду пауэрбанка и отслеживать состояние текущего использования устройства. Для администратора предусмотрены функции управления пользователями, станциями, устройствами, арендами и оплатами.
Структура работы: введение, 4 главы, заключение, перечень использованных информационных ресурсов и приложения. Работасодержит92страницы, 35рисунков, 1таблицуи26источников.
Annotation
The final qualification work is devoted to the design and development of a web application for renting portable charging devices in an educational institution. The developed system is intended to simplify the process of obtaining a power bank, monitoring an active rental, and returning the device through a rental station.
During the analysis of the subject area, the main functional requirements for the web application were determined, the features of organizing a power bank rental service were studied, and a comparative analysis of existing solutions was carried out. Based on the obtained data, the choice of development tools required for creating the user interface, the administrative section, and the database was justified.
As a result of the completed work, a web application was developed that allows users to register in the system, view available stations, rent a power bank, and track the status of the current device usage. For the administrator, the system provides functions for managing users, stations, devices, rentals, and payments.
The structure of the work includes an introduction, 4 chapters, a conclusion, a list of information resources used, and appendices. The workcontains92pages, 35figures, 1tables, and26 sources
